See it. Spec it. Send it.

Nothing counts until the people doing the work say it helps. Go ahead and try to get around that. The page will refuse you, and it'll tell you why.

This is a demo. The people are invented and there's no server. Everything runs in your browser and nothing leaves the page. The rules are the same code the real app runs, copied in by a script. Sign-in, the database and the password step-up aren't here. The repository is on GitHub.

The short version: watch the rule refuse

One click plays the same steps as the watch it refuse page in the repo. It starts a fresh item, so it clears what you've done.

Play a whole item, start to finish

Try it as a team. Post the problem as Nick (that's the SEE), switch to Steven or Cleo and add what you know in a comment, then back as Nick write the spec and send it. A different person, a leader, decides. Anyone can fork it, but a fork never inherits the approval. Effort is the AI that replies first, and the builder is a stand-in. Both are labeled as fakes here: no model, no database, no sign-in, and no money moves.

    The log

        • Real: the rules. This is a generated copy of the real state machine in core/machine.js, and a check fails if the copy drifts.
