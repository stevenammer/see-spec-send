# Roadmap

No dates. Status words are defined in [STATUS.md](STATUS.md). Items under Next are intentions, not promises.

## Done

- Forum workflow from SEE to SPEC to SEND, with frozen stages and nine recorded decision outcomes.
- Forking only for a real disagreement, stewardship transfer when a branch goes quiet, and deterministic closeout reports for each frozen stage.
- Department read scopes and opportunity propagation: restricted work shows others only that it exists and who to ask, and results are followed to other teams as labeled candidates.
- Correctable memory (challenge a derived record, erase a source and its derivatives) and saved, re-runnable questions to the organization.
- Continuous reanalysis: results are checked against earlier work, shown as linked updates, and a person can ask for a new decision. Earlier records never change.
- A working ledger (assumptions, questions, sourced estimates) and private on-device reflection after decisions.
- Private, opt-in mentoring, a guided problem-discovery flow, a labeled AI participant and a metered model gateway, including a chat-style proxy that counts every call.
- Opt-in OpenCode, Claude Code and Codex builders with a metered gateway and isolated preview for try artifacts. The [status table](STATUS.md) lists the tests and limits.
- Mutation testing (a nightly run against the widened suite) and load testing on one machine, with numbers in the [runbook](RUNBOOK.md).
- Synthetic browser walkthroughs, a matching browser demo, and a fixture-only hosted demo. The [hosted demo runbook](HOSTED_DEMO.md) records the live checks.

## Next, in order

1. Complete the hosted demo's two-network reviewer sign-in check and walk one reviewer through the synthetic workflow.
2. Run the [one-department pilot](PILOT_GUIDE.md) and use the results to decide what the forum needs next.

## Later

Enterprise sign-in against a real tenant, an outside security review, and a real Microsoft Teams connector (the synthetic adapter and its rules are built; a tenant, Graph and Entra sign-in are not), a larger model-quality evaluation in the reanalysis and question lanes.

Real-tenant enterprise sign-in validation and rollout, PostgreSQL, a Microsoft Teams adapter, customer-owned storage, comparison of other coding agents, an optional external release watcher and SMS.

## Not planned

Scoring or ranking people, spending without a person's approval, and reading conversations by default.
