# Roadmap

No dates. Status words are defined in [STATUS.md](STATUS.md). Items under Next are intentions, not promises.

## Done

- Forum workflow from SEE to SPEC to SEND, with frozen stages and nine recorded decision outcomes.
- Forking only for a real disagreement, stewardship transfer when a branch goes quiet, and deterministic closeout reports for each frozen stage.
- Private, opt-in mentoring, a guided problem-discovery flow, a labeled AI participant and a metered model gateway, including a chat-style proxy that counts every call.

## Next, in order

1. A working ledger: assumptions, questions, research results and estimates become durable records with a status and sources.
2. Continuous reanalysis: new internal results are checked against earlier work and surfaced as linked updates, with a path to a new decision.
3. Read scopes and opportunity propagation: results are followed to other teams as labeled candidates, with department boundaries enforced before anything is retrieved.
4. A real coding agent through the metered proxy, starting with one open-source agent in a locked container on free model lanes.
5. Memory you can correct, so derived records can be challenged and removed along with their sources.
6. Private reflection after decisions, kept only on the person's own device.
7. Ask-the-organization questions with saved, re-runnable, contestable answers.
8. One end-to-end synthetic walkthrough in a real browser, and a matching demo.

## Later

Mutation and load testing, enterprise sign-in, PostgreSQL, a Microsoft Teams adapter, customer-owned storage, comparison of other coding agents, an optional external release watcher and SMS.

## Not planned

Scoring or ranking people, spending without a person's approval, and reading conversations by default.
