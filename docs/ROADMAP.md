# Roadmap

No dates. Status words are defined in [STATUS.md](STATUS.md). Items under Next are intentions, not promises.

## Done

- Forum workflow from SEE to SPEC to SEND, with frozen stages and nine recorded decision outcomes.
- Forking only for a real disagreement, stewardship transfer when a branch goes quiet, and deterministic closeout reports for each frozen stage.
- A working ledger (assumptions, questions, sourced estimates) and private on-device reflection after decisions.
- Private, opt-in mentoring, a guided problem-discovery flow, a labeled AI participant and a metered model gateway, including a chat-style proxy that counts every call.

## Next, in order

1. Continuous reanalysis, delivery half: people see the linked updates, can respond, and can ask for a new decision. The checking core is done.
2. Read scopes and opportunity propagation: results are followed to other teams as labeled candidates, with department boundaries enforced before anything is retrieved.
3. A real coding agent as a registered builder in the locked container. A first live trial through the metered proxy worked.
4. Memory you can correct, so derived records can be challenged and removed along with their sources.
5. Ask-the-organization questions with saved, re-runnable, contestable answers.
6. One end-to-end synthetic walkthrough in a real browser, and a matching demo.

## Later

Mutation and load testing, enterprise sign-in, PostgreSQL, a Microsoft Teams adapter, customer-owned storage, comparison of other coding agents, an optional external release watcher and SMS.

## Not planned

Scoring or ranking people, spending without a person's approval, and reading conversations by default.
